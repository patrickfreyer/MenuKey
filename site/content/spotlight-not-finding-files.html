When Spotlight stops finding files or apps, the cause is almost always one of three things: the index is still rebuilding after a macOS update, the folder is excluded in Spotlight's settings, or the index is damaged. Work through the fixes below in order; the first two take a minute, and rebuilding the index fixes the rest.

1. Check whether Spotlight is still indexing

After a macOS update or a migration, Spotlight rebuilds its index in the background, and results stay incomplete until it finishes. Open Spotlight with ⌘ Space and search for something: if it's indexing, you'll see a progress message. You can also check in Terminal:

mdutil -s /        # "Indexing enabled." is what you want to see

If it's indexing, leave your Mac on and plugged in for an hour or two before trying anything else.

2. Check Spotlight's result settings

Open System Settings › Spotlight and make sure the kinds of results you're missing, such as Documents, Folders or Applications, are switched on. A category that's off disappears from every search.

3. Check Search Privacy

In System Settings › Spotlight, click Search Privacy. Any folder or disk listed there is never indexed. Select a folder you need and click − to remove it.

4. Rebuild the index from Settings

Adding your disk to Search Privacy and removing it again makes Spotlight rebuild its index from scratch:

  1. Open System Settings › Spotlight › Search Privacy.
  2. Click +, choose your startup disk (usually Macintosh HD), and confirm.
  3. Wait a few seconds, select the disk in the list, and click −.

Indexing starts again and can take from minutes to a few hours, depending on how many files you have.

5. Rebuild the index from Terminal

If the Settings route doesn't help, erase and rebuild the index for your startup disk. You'll be asked for your password:

sudo mdutil -E /       # erase the index; Spotlight rebuilds it
sudo mdutil -i on /    # make sure indexing is on

6. Restart and update macOS

A restart clears a stuck indexing process. People have reported Spotlight missing installed apps after macOS updates, including during the macOS 26 betas, so install the latest update from System Settings › General › Software Update.

7. Check Finder's search scope

If the problem is Finder search rather than Spotlight, open Finder › Settings › Advanced. When performing a search decides whether Finder searches the whole Mac or only the current folder. A search limited to the current folder looks broken when the file is somewhere else.

Find files while Spotlight rebuilds

Until the index is back, find files by path instead of by search. In Finder, press ⇧ ⌘ G and type a path such as ~/Documents, using Tab to complete names. Or, in Terminal, find ~ -iname "*invoice*" searches without the index (slowly).

Launchers that read Spotlight's index, including Alfred, Raycast's file search and JumpKey, are affected by the same problem, so fix the index first. JumpKey's folder results from zoxide don't depend on Spotlight. For everyday tips, see how to find a file or folder on Mac.

Questions

How long does Spotlight take to reindex?

Usually from a few minutes to a few hours, depending on how many files your Mac has. Leave it on and plugged in.

Why does Spotlight show apps but not my documents?

Check that Documents is switched on in System Settings › Spotlight, and that the folder isn't listed under Search Privacy. If both are fine, rebuild the index.

Is it safe to rebuild the Spotlight index?

Yes. Rebuilding only recreates Spotlight's search database. Your files aren't touched, but search results are incomplete until indexing finishes.
