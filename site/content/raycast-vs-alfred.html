Raycast is the best pick if you want one free app with extensions, snippets, clipboard history and window management. Alfred suits people who prefer a one-time purchase and deep custom workflows. The Spotlight built into macOS 26 is now good enough for launching apps, finding files and simple actions, so many people don't need either.

Short version: start with Spotlight. Add Raycast if you want extensions and a big free feature set. Choose Alfred if you'd rather pay once than subscribe for the extras. We make JumpKey, a smaller free tool, and it appears in the table below with that bias stated.

Raycast vs Alfred

Both launch apps, search files and run commands from a keyboard shortcut. The real difference is how you pay for the extras.

  • Raycast gives most features away: clipboard history, snippets, window management and a store of extensions. Pro adds AI, cloud sync, unlimited clipboard history and custom window layouts for a monthly or yearly fee.
  • Alfred has a capable free version, including file search and menu bar search. Its Powerpack is a one-time licence that unlocks workflows, clipboard history, snippets and more. People who dislike subscriptions often prefer it.

Raycast feels more modern and is easier to extend. Alfred is lighter and has years of community workflows. Neither is open source.

Spotlight vs Alfred

macOS 26 redesigned Spotlight. It now has separate views for apps, files, actions and clipboard history (⌘ 1 to ⌘ 4), and it can run shortcuts and app actions. That covers what many people bought Alfred for. Alfred still wins on custom workflows, snippets and fine control over results.

Spotlight vs Raycast

Spotlight needs no install. Raycast still goes further: extensions for tools like GitHub and Linear, snippets, window layouts and a scriptable command system. If you only launch apps and open files, Spotlight is enough.

Where JumpKey fits

JumpKey is not a full Raycast or Alfred replacement. It has no clipboard history, snippets or extensions. It does four things from one shortcut: run any menu command of the app you're in, switch to an open window, open any menu bar icon, and jump to files and folders ranked by how often you use them. It's free, open source and makes no network requests. See the Raycast alternative page or the Alfred alternative page for when that's enough.

Questions

Is Raycast better than Alfred?

For most people starting fresh, Raycast offers more for free. Alfred is better if you want a one-time purchase, or already rely on its workflows.

Is Alfred still worth it in macOS 26?

The new Spotlight covers basic launching, file search and clipboard history. Alfred is still worth it for custom workflows, snippets and precise control.

Can Spotlight search menu items?

Only inside one app at a time, using the search field in that app's Help menu (Shift-Command-/). Alfred, Raycast and JumpKey can search the menus of the app in front from their own shortcut.
