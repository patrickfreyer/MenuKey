The fastest way to find a file on a Mac is Spotlight: press ⌘ Space, type part of the name, and press Return. If you know roughly where it is, Finder search or Go to Folder is quicker. If you open the same folders every day, a launcher that learns them gets you there in two or three letters.

Quick answer: ⌘ Space and type the name (Spotlight). In macOS 26, press ⌘ 2 in Spotlight to see files only. In Finder, ⌘ F searches with filters, and ⇧ ⌘ G jumps to a path you type.

1. Spotlight: search the whole Mac by name

Spotlight searches file names, the text inside documents, apps and settings. Press ⌘ Space and type a few letters of the name. Use the arrow keys to pick a result, then:

  • ↩ opens the file.
  • ⌘ ↩ shows it in Finder, so you can see which folder it lives in.
  • ⌘ 2 (macOS 26 and later) switches Spotlight to its Files view, which hides apps, actions and web suggestions.

You can narrow a search with a kind: kind:pdf invoice finds PDFs with "invoice" in the name or text, and kind:folder projects finds folders only.

2. Finder search: filter by kind, date and place

Open a Finder window and press ⌘ F. Type the name, then choose whether to search This Mac or only the folder you're in. Click + under the search bar to add filters, such as Kind is PDF, or Last opened date is within the last week.

To make every Finder search start in the current folder, open Finder › Settings › Advanced and set When performing a search to Search the Current Folder.

3. Go to Folder: jump straight to a path

In Finder, press ⇧ ⌘ G and type a path such as ~/Documents/Finance. Press Tab to complete folder names as you type. This is the quickest way into folders Spotlight hides, such as ~/Library.

4. Recents and recent folders

If you used the file lately, you may not need to search at all. Recents in the Finder sidebar lists files you opened recently. For folders, open the Finder menu bar and choose Go › Recent Folders.

5. Terminal: search by name from the command line

Terminal can query the same Spotlight index, which is handy in scripts or when you want plain paths:

mdfind -name invoice                 # names containing "invoice", from Spotlight's index
mdfind -onlyin ~/Documents "kind:pdf"   # PDFs in Documents
find ~ -iname "*invoice*" 2>/dev/null   # slow, but works without the index

If you live in the terminal, zoxide learns the folders you visit, so z fin jumps to ~/Documents/Finance after a few visits.

6. A launcher that learns your folders

Spotlight ranks results the same way whether you opened a folder once or every day. JumpKey, a free and open-source launcher, ranks files and folders by frecency: how often and how recently you open them. Press ⌥ Space, press Tab to Files, and type a few letters.

  • ↩ opens a file in its app, or a folder in Finder.
  • ⌘ ↩ shows a file in Finder, or opens a folder in Terminal or your favourite terminal app.
  • It reads zoxide's history too, and adds every folder you open back to it.

JumpKey uses Spotlight's index for file names, so if Spotlight is missing files, fix that first: see Spotlight not finding files.

Questions

Why can't Spotlight find a file I know is on my Mac?

Usually the folder is excluded under Spotlight's Search Privacy settings, the index is still building after an update, or the index is damaged. The fixes are in our guide to Spotlight not finding files.

How do I search for folders only on a Mac?

In Spotlight, type kind:folder followed by part of the name. In Finder search, add the filter Kind is Folder. In JumpKey, type z and a space before the name.

How do I find where a file is saved on a Mac?

Select it in Spotlight and press Command-Return to show it in Finder. In a Finder window, choose View › Show Path Bar to see the full path at the bottom.

How do I find recently opened files on a Mac?

Click Recents in the Finder sidebar, or open the Apple menu and choose Recent Items. For folders, use Go › Recent Folders in Finder.
